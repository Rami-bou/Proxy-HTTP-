# HTTP Proxy with Content Filtering

A simple HTTP proxy developed in Python using TCP sockets. It intercepts HTTP requests from a browser, forwards them to web servers, and supports configurable content filtering.

## Features

- HTTP request parsing and forwarding.
- HTTP header modification.
- Website blocking through configuration.
- Content filtering and HTML modification.
- Browser integration through a local proxy.

## Technologies

- Python 3
- TCP Sockets
- HTTP Protocol
